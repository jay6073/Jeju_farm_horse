# 전년·금년 예산 비교

수익·비용·자본을 한 페이지에서 비교하고 엑셀로 내려받는 웹 페이지입니다.

## 실행

`index.html`을 더블클릭하거나 브라우저로 엽니다.

```bash
# 선택: 로컬 서버
npx --yes serve .
```

## 기능

- 비용·자본 한 표 / 수익 별도 표
- 전년·금년 입력 및 증감 자동 계산
- 항목 추가·삭제
- 엑셀(.xlsx) / CSV 불러오기
- 엑셀 내려받기 (요약 / 사업명별 / 비용 / 자본 / 수익 시트)

자세한 요구사항: [docs/예산비교-요구사항.md](docs/예산비교-요구사항.md)
